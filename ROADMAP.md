# Product Roadmap

Future development, feature enhancements, and architectural goals for **Daybook**.

---

## 🎯 Next Release (v1.3.0)
- **Custom Date Range Filter**: Interactive date range selector for custom report analytics.
- **Diary Rich Text Formatting**: Bold, italic, and bullet list tools inside the journal editor.
- **Custom Notification Sounds**: Tone picker for calendar reminder push alerts.
- **Task Subtasks**: Nested checklists inside individual tasks.

---

## 🚀 Planned Features
- **Habit Streak Calendar**: Visual monthly grid view for tracking habit streaks over time.
- **Multi-Language Support (i18n)**: Localization for Spanish, French, German, Hindi, and Japanese.
- **Custom Task Tags**: Custom color-coded labels beyond default categories.
- **Voice Memo Reflections**: Attach short audio recordings to diary entries.

---

## 🎨 UI & UX Improvements
- **Primary Color Picker**: Accent color customization in settings.
- **Interactive Onboarding**: First-launch feature walkthrough carousel.
- **Celebratory Micro-Animations**: Confetti effects upon completing daily goals.
- **Tablet & Foldable Layouts**: Dual-column layout for wider screen displays.

---

## ⚡ Performance & Optimization
- **SQLite Query Pagination**: Lazy-loading pagination for large diary entry histories.
- **Image Compression**: Auto-resizing profile photos before local storage saving.
- **Virtualized Lists**: Render optimizations for long task and reminder lists.

---

## 🔒 Security & Privacy
- **Database Encryption**: Full AES-256 SQLCipher encryption for offline SQLite data.
- **Inactivity Auto-Lock**: Automatic app lock timer on background inactivity.
- **Two-Factor Authentication**: Optional 2FA for Firebase user accounts.

---

## 💡 Long-Term Goals
- **Cloud Sync Engine**: Background SQLite-to-Firestore synchronization with offline conflict handling.
- **Desktop Apps**: Cross-platform macOS and Windows desktop builds.
- **Smartwatch Companion**: Quick task check-ins from Wear OS & Apple Watch devices.
